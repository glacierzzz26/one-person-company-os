# One-Person Company OS — 项目详解

> 全局背景、数据流、技术栈与边界。续接阶段工作前先读本页 + [进度总表](进度总表.md)。

## 定位

构建一个由**一个人负责最终决策、AI Agent 承担大量执行**的公司操作系统(Company Operating System)。不是超级 Chatbot、不是 Agent Framework、不是纯 Workflow Engine、不是 ERP。

方向基线(最终版,不轻易改动):`docs/../One-Person-Company-OS-Design-v1.0.md`(内容 v1.1)。

## 核心模型(v1.1 修正)

- **Agent 是 Capability 中的执行角色**(组织/角色维度):`Company → Capability → Agent`
- **Workflow 是跨 Capability 的流程编排**(流程/方法维度):`Workflow → Task → Execution → Runtime → Tool`
- 二者不在同一层级。Verification / Approval 属于**治理链**,按风险策略触发,不是每次执行必经。
- 治理:Policy 由系统强制实施,Agent 在受控环境无法直接改 Policy/Permission、删 Audit、绕过 Approval。
