## 实施期修订(相对冻结契约)

1. **Upsert 实现改 repo 层 Get→insert/update**:契约原拟 sqlc 层 `INSERT … ON CONFLICT … DO UPDATE … RETURNING *`,但 sqlc v1.31.1 SQLite 方言**不解析 upsert RETURNING**(`mismatched input`)。改为纯 `INSERT … RETURNING` + `UPDATE … RETURNING` 两查询,repo `Upsert*` 先 Get 判存在再分派 —— 行为等价(单用户),repo 层仍是单一写入口。
2. **db/queries/*.sql 保持纯 `-- name:` + SQL、无自由注释**(含长中文/内嵌关键字如 RETURNING 的说明性注释):实测 sqlc 对含此类头注释的文件「edited query」预处理解析异常,连文件内首条最简 SELECT 都被连带报错;隔离后纯风格文件全过。与既有全部 query 文件风格一致,属仓库既有约束,后续子阶段沿用。
3. **queue_work INTEGER↔bool**:domain 用 bool(json 友好),repo mapper `boolInt` 转 0/1(契约 §六 风险已预告,落地同语义)。
4. **repo UpsertSecret 时间戳 repo 内取 now()**(不依赖调用方填 UpdatedAt);AppSetting/CompanySetting 的 UpdatedAt 由 service 层写入前打点(与 AddEndpoint 等既有风格一致)。
