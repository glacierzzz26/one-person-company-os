## 实施期修订(相对冻结契约)

1. **`TestSetupWithoutKeyPath` 补设**:契约 §五 未单列「server 未配 key 路径」的 500 守卫用例,实施时补 `TestSetupWithoutKeyPath`(断言 SetupWithoutKeyPath 500)凑齐失败分支覆盖。
2. **轮换/初始化 UI 状态自洽**:Settings 页轮换成功只 `setToken(new)`(旧即失效,当前会话无缝续用),不触发全局 bump(initialized 不会因轮换而变,避免多余整页重拉)。
3. **AuthModal 文案统一「控制台令牌」**:401 提示与 /setup/DB 哈希说明随本轮术语收口(client.ts 401 message + AuthModal 标题/正文),与契约 3.6 一致。
4. **setup whitelist 全路径匹配**:`apiAuth` whitelist 比对 `r.URL.Path` 须含 `/api/v1` 前缀(即 `/api/v1/setup/status`、`/api/v1/setup`),不能只比 `/setup/status` —— 否则第二次 status 拉取被 401。
