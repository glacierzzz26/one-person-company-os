## 实施期修订(相对冻结契约)

1. **B2 摘要窗口外审批不计**:契约 §五 未显式说窗口外审批,实施以窗口过滤为准(48h 前 decided 的审批不进当日计数)——与 gatherDigestFor 既有窗口语义一致,补断言。
2. **CreateApproval 只插 pending**:store.CreateApproval 只写 ID/TaskID/Risk/Reason/RequestedBy/CreatedAt,Status/DecidedAt 忽略(插入即 pending),测试种子须经 `UpdateApproval(id,"approved",…)` 落地已决审批 → `seedDecidedApproval` helper。
3. **serverconfig 缺省语义**:`effectiveServerConfig` 对零值 AppSetting 会零填内置默认(缺行由 `svc.AppSetting` 先回默认),故 D 用例以 `settings.DefaultAppSetting()` 为「零配置启动」真是输入,越界分支须经显式 flag(Changed)才可达。
4. **rotate guards 补设**:契约 §五 列了成功路径,未列未初始化/无 key 路径守卫 → 实施补 `TestE4RotateGuards`(400 not_initialized、500)凑齐失败分支。
5. **`notify.New` 空 webhook = nil**:决策②删 `NewFromEnv`,适配为 `New(webhook,secret)`;空 webhook 返回 nil 同旧语义,`TestNilNotifierDisabled` 补该断言;原 env 用例改构造语义。
6. **service/notify.go 与 internal/notify/notify.go 两处 pre-existing 注释排版**:文件本轮在改单内,顺手 gofmt(仅注释对齐,零语义)。
