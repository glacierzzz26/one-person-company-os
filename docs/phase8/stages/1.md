## 交付物

`internal/provider` **纯新增 4 文件 + 1 处注释标注**,service/endpoint/迁移/sqlc/go.mod 零改动:

| 文件 | 内容 | 说明 |
|---|---|---|
| `messages.go` | OpenAI Chat Completions 方言类型 `Message/ToolCall/Tool/ChatRequest/ChatResponse` + 消息构造助手(`Sys/User/Assistant/AssistantToolCalls/ToolResult/FuncCall/ToolDef`)+ arguments 互转(`ArgumentsFromRaw/ArgumentsToRaw`) | json tag 即网关线格式;role=tool 回填引用 `tool_call_id` |
| `chatter.go` | `Chatter` 接口(多轮原生 tool-call:Chat → 有 ToolCalls 则 Go 执行 → ToolResult 回填 → 再 Chat) | 取代 `Generate` 单次文本形态;8.x 新调用一律走它 |
| `openai.go` | `NewOpenAI(baseURL, key, model)` + `Chat`:`{base}/v1/chat/completions`,`Bearer` 单 key(空 key 不发头),system 首条消息,tools function 形态,响应归一 `Content/ToolCalls/FinishReason` | 5min 默认超时可注入;非 2xx → 带体摘要错误;`parseChatResponse` 容错(content=null、type 缺省补 function、content_filter→stop) |
| `chatstub.go` | 确定性 `ChatStub`(`NewChatStubText/Script/Error`):按序吐应答(先 tool_calls 再收文本),耗尽重复末条 | scripted 保真的工具语义档;8.2 离线 tool 回合假后端 |
| `claudecli.go`(注) | `ClaudeCLI` 头注标 `Deprecated`(0-7 legacy 文本后端保留;claude Code agent 委派属 8.5,独立路径) | 代码零改动 |
