## 验证

- `gofmt` 本次改动干净(其余 pre-existing 未格式化文件不动);`go vet ./...`、`go build ./...` 干净;`npx tsc --noEmit`(web)干净。
- `go test -count=1 ./...` 全绿;**0–7 与 8.1 既有测试零改动**;8.2/8.3 测试仅按新契约适配(见下);`go test -race -count=1 ./internal/service/` 亦绿。
- 用例对照设计 §五:
  - **C1/C2** `TestDefaultTierResolutionOnCreate`:配齐三档(同档双端点 created_at 错开)建单全空 → review=最早 frontier、test=最早 standard、writer=cheap+anthropic 落位并持久化;create audit detail 列 `reviewer=<id>:frontier-model-1;test=…;writer=…`。
  - **C3** `TestExplicitEndpointSkipsDefaultResolution`:显式槽原样不改(即便档不匹配);只给 reviewer → 仅空 test 槽默认解析;全显式 → create audit detail 为空。
  - **C4** `TestJudgeSlotHardFailsWhenTierUnmet`:无 frontier → review 槽建单硬失败(消息含 tier=frontier/reviewer/os endpoint/--reviewer-endpoint);有 frontier 无 standard → test 槽硬失败(含 tier=standard/test/--test-endpoint)。
  - **C5/C6** `TestWriterTolerantAndScriptedSkip`:无 cheap+anthropic → writer 留空建单成功;scripted 全空 → 成功且零解析零落槽(离线红线)。
  - **B1** `TestEngineEndpointForTestSlot`:test 优先 test 槽 → 回退 reviewer → writer;review 不受 test 槽影响(reviewer → writer)。
  - **A2 补充** `TestEndpointTierDefaultToStandardOnCreate`:CreateEndpoint 未给 tier → 落 standard(mapper 归一,INSERT 显式列不再绕过 DEFAULT)。
  - **C8** `TestAPISelectEndpointTier` / `TestAPICreateTaskEchoesTestEndpoint`(server):add 端点落 standard;select 带 tier=frontier 落库回读 + 非法 tier 校验消息 + audit detail 带 tier;POST /tasks 显式 test_endpoint_id → 201 回读。
- 既有 8.2/8.3 适配:seedEndpoint(未给档 → repo 归一 standard)后「显式 reviewer + 空 test 槽自动解析到同端点(与原 reviewer 回退同效)」用例(RoundLoop/SharedWorkspace/ReworkHint)零改动即绿;纯 writer 路径无判读端点用例(EmptyDiff/AgentCLI/ResidueRecovery/Driver baseline 三处)补 `seedJudgeDefaults`(frontier+standard 两行,假 baseURL 不触网)过建单默认解析。

## 实施期修订(相对冻结契约,详见 tier-enforcement.md §七)

1. **repo CreateEndpoint 空档归一 standard**(上文交付物表):INSERT 现显式列 tier 后,未标档调用点会以空串绕过 DB DEFAULT → mapper 归一补回「默认落中档」语义。
2. **中文标注归展示层**:console(JS)本就不能 import Go,单消费者 CN map 在 service 是死码 → CLI tierCN / console tierLabel 各自持有;service 只持常量与解析。
3. **CLI list/show TIER 用中文标注**(契约 §三 D 原拟「取原值与 ROLE 同风格」实施改判,循方向 §十 1 与 CLI 通篇中文);console 以独立「档位」列呈现。
4. 默认解析收敛单钩子 `applyEndpointDefaults`,create audit 命中明细只在确有落档时非空(显式给齐保持既有空 detail)。
