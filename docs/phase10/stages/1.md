## 实施期修订(相对冻结契约)

1. **sqlc nullable FK 参数形态**:`task.project_id` 在 WHERE/UPDATE 查询(CountActiveTasksByProject / ClearTaskProject / ListTasksByProject)生成 `sql.NullString` 参数,Store 层以 `ptrToNull(&id)` 接;INSERT 里 project_id 是普通 string 参数(无歧义)。
2. **CreateTask INSERT 占位符对齐**:扩列后 VALUES 一度 30 个 `?` 对 29 列 → `INSERT has more expressions than target columns`;改为逐列 29 占位符后过。
3. **用例对齐契约 P-list(不越界)**:初稿试测「disabled 流水线不可 run / 空意图 ErrInvalid」两防御分支,均需 service 本期不存在的 status 写面/空 description 制造 → 契约本期无此用例,按「测试只覆盖契约承诺」从文件剔除(service 无 status 写,10.2 再说)。
4. **server 包无 env seam → run 建单走 DB 默认 live**:server 测试与二进制冒烟都需先落 8.4 判读档端点(frontier/standard)才过 run 建单(只建单不触网;执行不在本层)。这正是 9.4 反向门控的预期产品行为。
