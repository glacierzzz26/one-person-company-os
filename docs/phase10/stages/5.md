## 实施期注意(相对契约的落地裁定)

1. **Gsrv-1 首写断言 code_source bound 是错的**:ensureCodeSource 只认 GitHub 可解析 origin → 本地 path 克隆后
   code_source = null(通道 B 只服务于 GitHub 仓库;本地源项目 = 无代码源)。改为断言 null;GitHub 绑定形状由
   Vsrv-1 离线盖(已 git + GitHub origin 建项目 → code_source 富化)。真实公开 GitHub clone 的 HTTP 端到端
   会留 live 人工验证点(见下边界)。
2. **live HTTP dogfood 用 CLI actor 代替**:os.db 已初始化 console token(明文未知,Phase 9 遗留)→ /api/v1
   鉴权开、无法匿名 HTTP。CLI 直开同一 os.db 走 `CreateProject`(actor human:cli)→ **与 Web/HTTP 同一 service
   CreateProjectAs**,clone 语义同源;Web/HTTP 路径的离线自动覆盖 = Gsrv-1(真 HTTP 同源)。
3. **run 前拉取 live 端到端未跑**:需 live 引擎端点 + worker 真实认领;本环境无 live 模型端点/QueueWork 关 →
   以 GC6/GC7(真 git binary + 本地 remote 前移/全部跳过守卫)+ dogfood ws `git pull --ff-only` 可达等价覆盖,
   **如实标注边界**。
