## 三、契约对齐(数据诚实)—— 原型 mock 与真契约的差异按如下处理

逐字对照 12 个域 model.go + api.go + service/overview.go/intake.go 后,原型的几处 mock 在真契约下不存在/不同,
前端一律以真契约为准(不发明字段):

| 原型 mock | 真实契约 | 7.3 处理 |
|---|---|---|
| approvals 行带 task_title | `GET /approvals` 返回裸 `Approval`(无标题);标题只在 `overview.pending_approvals`(ApprovalView) | 审批中心行标题懒取 `GET /tasks/{id}`(组件级 memo 缓存) |
| endpoint.has_token / models_cache[] | `token_enc`(string,空=无)、`models_cache`(string=provider 原始 JSON) | 只显示 token_enc 非空指示;models_cache 防御 parse(对象/数组兜底)成快选 chips |
| repo 行 issues_open/last_sync | Repo 仅登记元数据;账本只在 `overview.rd.ledger` | 删列;账本入口引导至总览 RD 卡 |
| ledger 键 `ask_human` | disposition 真键 = `ask` | 渲染 direct_work/merge/skip/ask |
| done_7d + sparkline | 无此数据 | 换 `rd.by_status.completed` 数值卡,不做 sparkline |
| 决策 kind engineering/pricing/hiring、status superseded | kind=`approval\|goal\|strategy\|policy_change\|capital\|manual`;status=`made\|pending\|executed` | 表单/筛选/展示全用真枚举 |
| 记忆 type insight/playbook/fact、tags 逗号分隔 | type=`lesson\|knowledge\|project_context\|decision_ref\|architecture\|convention\|task_history`;tags **空格分隔**字符串 | 真枚举;tags 按空白 split |
| 执行状态 succeeded | `running\|completed\|failed\|timeout` | 状态色/文案按真枚举 |
| 审批/审计按公司 | approvals、audit **全局**(无 company 参数) | 页面/徽标不按公司过滤,mono 注明 |
| overview 空态数组 | Go nil slice → JSON **null**(capabilities/workflows/pending_approvals) | 前端统一 `?? []` 兜底(线上发现后修复) |
| task/execution result/last_error 可空 | string(空串非 null) | 按 truthy 判断展示 |
| intake/sync 离线可跑 | 需 `OS_ISSUE_SOURCE=fixture` + `OS_ENGINE_MODE=scripted`,否则 500 | 报错 toast 如实呈现,不崩 |

## 四、实现要点

- **embed 与目录边界**:`go:embed` 不能引用包目录树外文件 → 内嵌目录 `internal/console/ui/` 只提交占位
  `index.html`(全新检出 `go build ./...` 仍绿);`make ui` 把 `web/dist/*` 拷入(除 index.html 全 gitignore)。
  SPA fallback 严格:仅「无扩展名且文件不存在」→ index.html;/api、/healthz、带扩展名缺失 → 404;非 GET → 405。
- **数据层零状态库**:`types.ts` 手写(契约即类型),fetch 拆信封 + Bearer(localStorage `os.token`),401 → 全局
  setUnauthorizedHandler 弹 AuthModal;`useData`(JSON.stringify deps + interval + refreshKey bump 联动)。
- **主题**:三态(浅/深/随系统)经 `document.documentElement.dataset.theme` 落到 CSS 变量;状态色/堆积条只用
  CSS 类(`.pill-*`/`.sb-*`/`.tx-*`)与语义 token,不在 TS 里写死 hex(避免暗色失真);Sider 恒深色。
- **轮询**:overview 15s、审批中心 15s、待审批徽标(store)15s、审计 20s、/healthz 20s;写操作后 bump() 全局刷新。
- **boot 门**:companies 未载→Spin;空库→CreateCompanyScreen(POST /companies);有库→顶栏公司 Select
  (localStorage `os.company` 记忆);路由 8 视图 + `*`→总览。
