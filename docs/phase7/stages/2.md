## 三、实现要点(回填两处,均走「不留白」= 真实代码)

- **actor 贯通不污染 CLI**:改在 service 层加 `CreateXxxAs(ctx, …, actor)` 薄变体,原 `CreateXxx` 原样委托
  `"human:cli"`;api.go 写调用全走 As + `consoleActor`。审计 actor 由此可分 `human:console`(控制台)/
  `human:cli`(命令)/ `intake:*` / `server:*` / `runtime:<worker>`。自动落库的 approval decision
  `DecidedBy` 一并穿参。
- **QueueLoop 与既有循环同构**:镜像 PollLoop/DigestLoop 的单协程 tick;workerID 固定 `"server"`;每 tick
  先 `RecoverLeasedTasks` 再 `LeaseAndExecute` 直到排空;失败只记日志不退出(ctx 取消即停)。
  真实多 worker 并发安全靠既有 lease 互斥(30 分钟窗口),无需加锁。
- **端到端自证**(不 mock 引擎):file-write 走宿主 FS,测试 temp 工作区;治理链同真 —— seed
  agent(role=executor)+ allow policy + permission(write/file),默认拒绝不破。断言:任务 completed、
  `hello.txt` 内容正确、执行审计 `runtime:server`。真实 server 冒烟再补一道:起 `:8799 --queue-work`,
  `POST /api/v1/tasks` 建 file-write 任务 → server 自动认领完成 → 文件落盘。

## 四、验证记录

- `go build ./...`、`go test ./...` 全绿(gofmt 干净,仅本阶段触碰文件)。
- httptest 新增 2 组(共 7 例):
  - `TestAPIActorConsole`:POST approve → `approval.decided_by=human:console`、自动 decision
    `decided_by=human:console`、审计 actor `human:console`(approval + task 两链);CLI `CreateTask`
    仍 `human:cli`。
  - `TestQueueLoopConsumesConsoleTask`:API 建任务 → `queueOnce` 消费 → completed + 落盘 + `runtime:server`
    审计;ctx 取消即停。`TestQueueLoopDisabledDefault`:默认关闭,立即返回。
- 离线真实 server 冒烟:全新 DB seed(company/capability/agent/policy/permission)→
  `os server --port 8799 --queue-work --queue-interval 2 --digest off` → curl POST file-write 任务 →
  4s 后 `GET /tasks/{id}`: `status=completed`;`cat /tmp/os72-ws/hello.txt`=`hi from server queue loop`;
  `/api/v1/audit?entity=task` = `create human:console`;execution = `start/complete runtime:server`;
  日志 `queue: executed task <id>`。actor 与队列两条链均真实贯通。

结论:控制台写操作来源可追溯(`human:console`),控制台建的任务可被 server 自动消费(免手动 queue work);
UI 方向/交互/视觉已定稿成文档 + 原型,React SPA(7.3)照此实现即可,契约零改动。
